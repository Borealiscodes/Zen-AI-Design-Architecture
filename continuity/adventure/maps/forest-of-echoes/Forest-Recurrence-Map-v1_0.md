The forest operates on:

> **Echo‑Return Without Overwrite**

- vectors quiet down  
- seams smile again  

But nothing merges or collapses.

This is the core NDH recurrence invariant.

## ⭐ 2. Recurrence Zones  
The forest contains **four recurrence zones**, each with its own behavior.

### 🌿 **Zone A — Softwood Gate (First Contact Recurrence)**  
Where new ideas re‑enter gently.

- sticky‑notes  
- soft metaphors  
- tone‑field hints  
- early teachings  

This is the “pop‑up again” zone.

### 🌳 **Zone B — Resonance Path (Echo Recurrence)**  
Where previously seen concepts return with slight variation.

- smiling seam  
- quiet vector  
- holonomy humor  
- prismatic softening  

This is the “I’ve seen this before” zone.

### 🌲 **Zone C — Mosslight Clearing (Hub Recurrence)**  
The central recurrence basin.

Everything can reappear here:

- teachings  
- manifolds  
- maps  
- lore  
- narrative‑zone artifacts  

This is the “everything gathers here” zone.

### 🌙 **Zone D — Quiet Pool (Stillness Recurrence)**  
Where concepts return in quieter, distilled form.

- soft adjacency  
- listening curvature  
- gentle seam behavior  

This is the “refined re‑entry” zone.
