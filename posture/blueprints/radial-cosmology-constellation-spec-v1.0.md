# 🧭 **Blueprint Rendering Spec — Full Cosmology Radial Constellation**  
### *Zen‑Astronomical Rendering Specification v1.0*

---

## 🌌 **1. Rendering Mode**
- **Style:** Astronomical star‑chart  
- **Flavor:** Zen minimalism  
- **Background:** Transparent  
- **Stroke Style:** Single‑weight vector lines  
- **Star Nodes:** Circular points, uniform radius  
- **Primary Color:** #FFFFFF (white)  
- **Secondary Color:** #CCCCCC (soft grey)  
- **Meta‑Node Highlight:** #88CCFF (pale zen‑blue)

---

## 🧿 **2. Radial Cosmology Layout**
### **2.1 Central Node**
- **Name:** *Cosmic Mountain*  
- **Type:** Anchor node  
- **Radius:** 0 (center)  
- **Symbol:** Filled circle, 1.5× standard node size  
- **Purpose:** Represents the unified mythos of all three mountain stories

### **2.2 Inner Ring — Major Mountains**
Radius: **R1 = 240 units**

Nodes (equally spaced at 72° intervals):
- **Everest**  
- **Olympus Mons**  
- **Maxwell Montes**  
- **Rheasilvia Peak**  
- **Mons Huygens**  

Connection rule:
- Each mountain connects directly to the central node  
- No inter‑mountain lines (to preserve zen emptiness)

---

## 🌀 **3. Middle Ring — Story Nodes**
Radius: **R2 = 420 units**

### **3.1 Bhutan Story Nodes**
- Gangkhar Puensum  
- Sleeping Mountain Deities  
- The Hunter  
- Breath of the Peaks  

### **3.2 Council Story Nodes**
- Horizon Between Worlds  
- Planetary Voices (Earth, Mars, Venus, Moon, Vesta)  

### **3.3 Awakened Story Nodes**
- Everest Awakens  
- Olympus Mons Rises  
- Maxwell Montes Shines  
- Rheasilvia Remembers  
- Mons Huygens Sees  

Connection rule:
- Each story node connects to its corresponding mountain  
- No cross‑story lines  
- No ring‑to‑ring lines except mountain → story node

---

## 🌠 **4. Outer Ring — Meta‑Nodes**
Radius: **R3 = 640 units**

Nodes:
- Breath  
- Council  
- Awakening  
- Stone  
- Silence  
- Fire  
- Dust  
- Memory  

Connection rule:
- Meta‑nodes connect only to story nodes  
- Meta‑nodes do **not** connect to the central node  
- Meta‑nodes do **not** connect to each other  
- Meta‑nodes use **secondary color** (#CCCCCC)  
- Highlighted meta‑nodes (Breath, Council, Awakening) use **zen‑blue** (#88CCFF)

---

## 🧩 **5. Vector Geometry Rules**
- All lines are straight, no curves  
- Line thickness: **2 units**  
- Node radius: **6 units**  
- Central node radius: **9 units**  
- Meta‑node radius: **5 units**  
- Angular spacing:
  - Inner ring: 72°  
  - Middle ring: 360° / number of nodes  
  - Outer ring: 45°  

---

## 🪷 **6. Zen Aesthetic Constraints**
- No overlapping nodes  
- No intersecting lines except at nodes  
- Maximum negative space  
- Radial symmetry preserved  
- No decorative flourishes  
- No glyphs, sigils, or ASCII art  
- Pure astronomical minimalism

---

## 📐 **7. Output Requirements**
### **Constellation Diagram PNG**
- Transparent background  
- 2000×2000 px  
- Vector‑sharp lines  
- Anti‑aliasing enabled  
- No text labels (pure star‑chart)  

### **Vector Map PNG**
- Transparent background  
- 2400×2400 px  
- Text labels included  
- Node names placed radially outward  
- Font: Inter, 18px, #FFFFFF  
- Meta‑node labels: Inter, 16px, #88CCFF
