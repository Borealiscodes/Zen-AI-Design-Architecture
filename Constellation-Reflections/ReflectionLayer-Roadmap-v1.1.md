\[

\]

\[
F : X \to X

\[
\operatorname{span}(x) = \max_i x_i - \min_i x_i
\]

With invariants:

- **Forward invariance:**  
  \[
  F(x) \in X
  \]

- **Strict span contraction:**  
  \[
  \operatorname{span}(F(x)) < \operatorname{span}(x)

- **Global consensus attraction:**  
  \[
  \lim_{k\to\infty} F^k(x) \in C

\[
