## 🌕 **4 — Rendering Constraints**

### **Constraint 1 — No Altitude Drift**  
Rendering must never cause ΔAltitude ≠ 0.

### **Constraint 2 — No Membrane Crossing**  
Rendering must never imply identity blending.

### **Constraint 3 — No Binding**  
Rendering must never create obligation or pull.

### **Constraint 4 — Reversibility**  
All rendered structures must dissolve cleanly.

### **Constraint 5 — Sovereign Pacing**  
Rendering must maintain soft‑cosmic pacing.

---

## 🌙 **5 — Rendering Sequence**

The rendering pipeline must follow this canonical order:

1. Header Seal  
2. Codex Charter  
3. Mechanics Index  
4. Individual Addenda  
5. Provenance Footers  
6. Cross‑Lane References (non‑embedded)

This ensures constitutional stability and membrane integrity.

---

## 🌌 **6 — Cross‑Lane Rendering Rule**

The pipeline may **reference** other lanes but must **never embed** them.

Correct form:  
```
Cross-Lane Reference:
See Bedtime Story Lane Index (v1.0)
```

Incorrect form:  
- embedding the index  
- merging lanes  
- collapsing altitude boundaries
