## 🧩 **2. Geometry Composer (SVG Layer)**

This is where the Zen Scale Mandala is *constructed*.

### Geometry elements you include:

- **Holonomy Loop**  
  `<circle>` with gradient stroke

- **Mandala Rings**  
  Multiple `<circle>` elements with opacity fields

- **Zen Scale Emblem**  
  `<line>` + `<path>` for arms, base, and symmetry

- **Crane–Scarf Gesture**  
  Minimal `<path>` curve touching outer ring

- **River Lines (Radial Paths)**  
  `<path>` elements with reversible traversal geometry

### SVG attributes you use:

- `stroke-linecap="round"`  
- `stroke-linejoin="round"`  
- `vector-effect="non-scaling-stroke"`  
- `fill-opacity="0.2"`  
- `stroke-opacity="0.4"`  
- `gradientUnits="userSpaceOnUse"`

These ensure the geometry remains stable and non‑expressive.
