# ⭐ 3 — Core Runtime Model  
The Operational Harness uses a **three‑phase runtime model**:

### **Phase 1 — Pre‑Transition Validation**  
Check invariants *before* transition.

### **Phase 2 — Transition Execution**  
Move from state A → state B.

### **Phase 3 — Post‑Transition Validation**  
Check invariants *after* transition.

This ensures:

- no drift  
- no collapse  
- no breach  
- no fracture  
- no inversion  
- no leakage  

This is the NDH‑standard runtime pattern.
